# Curvature-Aware Path Sensitivity

**Geodesic flow and Jacobi-field testbed** — how a small error in how a path is
started grows into a deviation further along, on surfaces where the answer is
known exactly and can therefore be checked.

![Geodesic flow and Jacobi fields on the three constant-curvature surfaces](figures/jacobi-testbed-v1.png)

A Jacobi field is the first-order separation between a nominal geodesic and a
neighbouring one. On a surface of constant curvature `K` its transverse
component satisfies

```text
j''(s) + K j(s) = 0,    j(0) = 0,    j'(0) = 1
```

with solutions `s`, `sin s` and `sinh s` for `K = 0, +1, -1`. This repository
integrates the geodesic flow and that equation numerically, checks both against
those closed forms, and — the part that actually matters — measures where the
first-order answer stops being an answer.

Everything below is regenerated by one command and recorded, with a pass/fail
threshold on every claim, in [`validation/report-v1.json`](validation/report-v1.json).

## Results

**109 declared checks, 0 failed.**

| what was measured | result |
|---|---|
| order of accuracy, Euler / midpoint / RK4 | 1.02 / 1.96 / 3.93 on the sphere, 0.97 / 1.98 / 3.97 on the hyperbolic plane |
| flat model | every method exact to `< 1e-13`; no order exists to measure, and the report says so |
| RK4 drift off the unit tangent bundle | `4e-14` (sphere), `2e-13` (hyperbolic), with no re-projection applied |
| separation of two geodesics | `sn_K(d/2) = sn_K(s)·sin(ε/2)` — one law of cosines for all three curvatures |
| error of the first-order prediction | grows as `ε²` with coefficient `cn_K(s)²/24`, matched to 3e-5 … 1e-4 relative |
| first-order validity at `s = 1`, to 1e-6 | `ε ≤ 0.52°` (sphere), `0.28°` (plane), `0.18°` (saddle) |
| conjugate point on the sphere | found at `s = 3.141592653589791`, error `2.2e-15` |
| loss of minimality past it | excess length matches `2(s - π)` to `7.1e-15` |

Two failure modes are measured rather than assumed. The **model** fails from
above, as `ε²`. The **numerics** fail from below — but only when the two
geodesics are flowed at different resolutions; advance the whole fan with one
shared step sequence and the truncation error is common-mode and cancels, giving
the separation to `3e-13` relative even at `ε = 1e-8`.

## Run it

```bash
pip install -e ".[dev]"
python examples/run_experiment.py --out out     # report + figure, exits non-zero on any failed check
pytest -q                                       # 76 tests, no network, a few seconds
```

Without installing:

```bash
PYTHONPATH=src python examples/run_experiment.py --out out
```

`--update-committed` refreshes the tracked `validation/report-v1.json` and
`figures/jacobi-testbed-v1.png`.

## Scope

The report's `claim_scope` is `numerical-verification-against-closed-form-solutions`.
Every number is checked against an analytic solution on a surface where one
exists. Three boundaries are kept explicit:

- A Jacobi field is a first-order variation, not the exact finite distance
  between trajectories. The size of that gap is measured here, not waved at.
- Finding a geodesic does not establish that an arbitrarily long segment is
  globally shortest. Past the conjugate point on the sphere it demonstrably is
  not, and the experiment measures by how much.
- No physical measurement exists in this repository. The bench that would
  establish agreement between prediction and measurement is described in
  `docs/INSTRUMENT.md` and has not been built.
